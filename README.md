## 🛤️ Concept & Metaphor

The entire portfolio is architected as an Indian Railways voyage:
- **Boarding Pass & Paper Ticket**: Centered vintage IRCTC-inspired paper ticket with tear edges, PNR (`ARNAV-2026`), and confirmation seal.
- **Station Master Announcements & Chime**: Interactive audio engine playing the station PA announcement with live departure board captions and animated waveform.
- **Vertical Main Line Route**: Connected railway tracks with moving train engine advancing down milestones as you scroll.
- **Real-World Delay Stories**: Stations highlighting authentic software engineering bottlenecks, lessons learned, and expandable technical details (data persistence, SPA 404 routing, CORS, MongoDB unique conflicts).
- **Ticket Confirmed / Final Destination**: Official rubber stamp, direct candidate links (Resume, LinkedIn, GitHub, Email), and traditional station blessing.

## 🚀 Tech Stack

- **Framework**: React 18
- **Bundler & Dev Server**: Vite
- **Styling**: Pure Modular Custom CSS (Mobile-first down to 375px)
- **Icons**: Lucide React
- **Audio System**: Web Audio API Chime + HTML5 Audio Engine

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/arnav-54/Wispr-hiring.git
cd Wispr-hiring
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```

---

## 🌐 Deployment

This project is a static React Single Page Application (SPA) with zero backend requirements. It can be deployed in 1 minute on **Vercel** or **Netlify**:

### Deploying on Vercel
1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **"Add New Project"** and select `Wispr-hiring`.
3. Keep default settings (`Build Command: npm run build`, `Output Directory: dist`).
4. Click **Deploy**.
